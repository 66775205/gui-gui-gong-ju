# 野路指南安卓安装包

安装包会在构建时复制网站页面、24 张拟饵照片、32 张鱼类照片和 12 张钓组照片。WebView 从安装包内读取页面和图片，图鉴无需等待网络加载；天气与地点查询仍需联网，定位仅在用户点击天气栏的定位按钮后请求权限。

`app/build.gradle` 的 `syncSiteAssets` 任务从仓库根目录同步网页文件到 APK assets。修改网页或照片后需要重新构建安装包，并替换网站 `downloads/yeluzhinan-android.apk`。每次发布提高 `versionCode`，才能覆盖安装旧版。

发布包使用 E 盘单独保存的 PKCS#12 签名文件。请保留同一签名文件和密码，以便后续版本覆盖安装；不要提交到公开仓库。
